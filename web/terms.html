1. 服务说明

1.1 服务内容

本平台为符合条件的在校大学生提供以下免费服务：

  • 在校学生身份验证（通过学校邮箱）

2. 用户注册与账号管理

2.1 注册要求

您必须使用本人真实有效的学校邮箱完成注册，并提供真实、准确、完整的个人信息。您应对您提供的所有信息的真实性负责，如因提供虚假信息导致的任何后果，由您自行承担。

2.2 账号安全

  • 您应妥善保管您的账号密码，不得将账号转借、出租或出售给他人
  • 您的账号下发生的所有操作均视为您本人的行为，由您承担全部责任
  • 如发现账号被盗用或存在异常使用情况，您应立即联系我们冻结账号

2.3 账号注销

您可以随时申请取消匹配，取消后：

  • 未完成的匹配将自动终止
  • 我们将按照《中意你FancyU 隐私协议》的约定删除您的个人信息

3. 用户行为规范

您在使用本平台服务时，应遵守法律法规、公序良俗及本协议约定，不得实施以下行为：

3.1 违法违规行为

  • 侮辱、诽谤、骚扰、威胁他人，侵犯他人合法权益

  • 攻击、入侵平台服务器或干扰平台正常运行
  • 恶意举报其他用户或提交虚假投诉
  • 其他损害平台利益或影响其他用户正常使用的行为

3.3 个人信息保护义务

  • 您仅可将通过本平台获得的他人联系方式用于与对方进行正常的交友沟通
  • 未经对方明确同意，不得将其联系方式泄露给任何第三方，也不得用于任何商业目的

2. 我们收集哪些个人信息

我们遵循"合法、正当、必要、最小"原则，仅收集为提供服务所必需的信息，绝不收集与服务无关的信息。

2.1 必须收集的信息（服务正常运行所必需）

  • 身份验证信息：您的学校邮箱地址

2.2 您自愿提供的信息

  • 联系方式：您自愿填写的邮箱等联系方式（仅用于配对成功后您主动选择向对方展示）
  • 问卷数据：您填写的价值观、生活方式、兴趣爱好、交友偏好等问卷答案

2.3 自动收集的技术信息

  • 此类信息仅用于优化服务性能和排查故障，不包含任何可识别您个人身份的信息

3. 我们如何使用您的个人信息

我们仅将您的个人信息用于以下明确列明的目的，绝不超范围使用：

  1. 验证您的在校大学生身份，为您创建账号并提供基础服务
  2. 运行配对算法，计算您与其他用户的兼容度并生成匹配结果
  3. 在您单独明确同意后，向匹配成功的对象展示您选择公开的联系方式
  4. 定期向您发送配对结果通知和重要服务公告
  5. 使用完全匿名化后的数据分析用户偏好，改进匹配算法和用户体验
  6. 维护平台安全，防范欺诈、恶意攻击等违法违规行为
  7. 响应您的咨询、投诉和权利请求

4. 配对算法特别说明

我们的配对服务基于自动化决策算法实现，我们保证算法的公平、透明和无歧视。

4.1 算法基本逻辑

配对算法基于您填写的问卷答案，通过计算价值观、生活方式、兴趣爱好等多个维度的相似度来生成匹配结果。

4.2 您的权利

  • 您有权要求我们对算法的基本逻辑进行说明
  • 您有权拒绝仅通过自动化决策方式为您配对
  • 您可以随时修改您的问卷答案，系统将在下一次配对中使用更新后的信息

5. 个人信息的存储与安全

5.1 存储地点

您的所有个人信息均存储在中国国内的服务器上，我们不会将您的个人信息传输至境外。

5.2 安全措施

我们采用行业领先的安全技术和管理措施保护您的个人信息：

  • 全站 HTTPS 传输加密，防止数据在传输过程中被窃取或篡改
  • 所有敏感数据采用 AES-256 算法加密存储
  • 邮箱地址与问卷数据物理分离存储：问卷数据仅以随机生成的 ID 存储，即使是平台维护团队也无法将问卷数据与特定用户关联
  • 严格的内部数据访问权限控制：仅核心技术人员在必要时才能访问数据，且所有访问操作均有完整日志记录
  • 定期进行安全漏洞扫描和渗透测试，及时修复安全隐患

5.3 数据保存期限

我们仅在实现服务目的所必需的最短期限内保存您的个人信息，保存期限届满后，我们将立即对您的个人信息进行删除或匿名化处理。

6. 个人信息的共享与披露

我们不会出售、出租或以任何方式向第三方转让您的个人信息。仅在以下极少数情况下，我们才会披露您的个人信息：

  1. 经您单独明确同意：在获得您的书面或电子形式的单独同意后，向您指定的第三方披露
  2. 法律要求：根据法律法规、司法机关或行政机关的合法要求进行披露
  3. 紧急情况：为保护您、其他用户或公众的生命财产安全，在必要的范围内进行披露
